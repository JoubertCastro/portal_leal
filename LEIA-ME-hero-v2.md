# Proposta 02 — Hero Leal

O arquivo original no Figma não foi alterado: a API informou limite de chamadas do plano Starter.

- hero-leal-v2.html: prévia autônoma com imagens incorporadas, desktop/mobile, transparência e backdrop-filter blur(24px). Nenhum CPF é transmitido.
- hero-leal-v2-figma.svg: composição desktop de 1440 × 930 para importar no Figma, com imagens incorporadas e textos/formas separados. A importação e a preservação dos textos como texto não puderam ser verificadas. SVG não preserva backdrop blur nativo: aplicar Background blur de 24 px ao painel Consulta-glass após importar.
- assets/: imagens originais do site publicado, sem alteração dos arquivos.

Para incorporar: arraste o SVG para uma área livre do arquivo Figma e use como substituição visual do cabeçalho/hero, mantendo as seções abaixo e reconectando os links do protótipo. A fonte proposta é Manrope; a prévia usa Segoe UI como alternativa quando Manrope não está instalada.

Revisão visual realizada em navegador, desktop e largura de 390 px. Sete marcas verificadas: Banco Pan, Recovery, Mercado Pago, ARC4, BTG Pactual, Carrefour e Serasa.
